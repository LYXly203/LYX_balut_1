==**接口的使用及定义**：==
interface中定义的变量是全局常量，不可被修改，其中用interface关键字定义接口中再定义的类默认都是抽象类。

一个接口可以有多个父类接口，接口中方法的访问权限都是public

接口实现类的定义方式：先定义一个类，该类使用implements关键字实现接口，并实现接口中的所有抽象方法，解释如下：
					*若接口和抽象类本身都有抽象方法，子类必须重写父类中的抽象方法和父接口*

**==其他需注意：==**
1.static关键字修饰静态方法，方法中的代码块为静态代码块，接口中的静态方法可以直接使用接口名调用

2.接口的实现类，必须实现接口中的所有方法，否则报错    

3.接口不允许继承抽象类，但是允许一个接口继承多个接口
